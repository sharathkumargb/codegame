CODE QUEST — STARTER WEBSITE

Open index.html in a modern web browser to view the website. No installation or server is required.

Included files:
- index.html: page structure and lesson content
- style.css: responsive styling and visual effects
- app.js: language selection, interactive lesson output, and sound toggle

The Run button is a learning simulation: it displays the expected output for the selected example. It does not compile or execute arbitrary C, Python, or Java code. To add real code execution, connect a safe backend or a trusted code-execution service.
